# 考研每日一句

一个部署在 GitHub Pages 的轻量静态网站，每天显示一句考研鼓励语。保留暖色纸张卡片和霞鹜文楷字体，无需构建或后端服务。

## 功能

- **页面标识**：左上角显示原创书页与星光 SVG 图标，以及「考研每日一句」；随日间、夜间主题调整配色。
- **标签页图标**：浏览器标签页使用同款书页与星光图标，文件为 `favicon.svg`。
- **今日一句**：根据北京时间的日期，匹配并解码当天的句子。2026 年显示 `mm-dd`，其他年份显示 `yyyy-mm-dd`。
- **往期回看**：点击卡片下方的「往期每日一句」展开列表，按日期从近到远显示所有今天之前的句子，并标注日期和总数。列表不包含今天或未来内容，展开时才解码往期句子。
- **夜间阅读**：首次访问跟随系统配色；点击右上角的「夜间阅读 / 日间阅读」切换，并在本浏览器保存选择。浏览器禁用本地存储时，仍可切换当前页面。
- **仓库入口**：页面左下角提供带 GitHub 图标的按钮，在新标签页打开 [项目仓库](https://github.com/menggou1/27-kaoyan-daily-sentence)。
- **跨日更新**：页面跨过北京时间午夜时自动更新日期、句子和往期列表，无需刷新；从后台回到页面时立即检查时间。
- **阅读与无障碍**：适配手机，往期长列表在卡片内滚动；支持键盘展开和切换配色，尊重系统的减少动画设置。

当天无记录时显示「不在2027考研初试备考时间」，仍可回看已有往期；备考开始前显示往期空状态。加载失败或单条解码失败会显示对应提示。

## 校时、倒计时与开发者模式

- 日期下方显示距离 **2026-12-19 08:30:00（北京时间）**的天、时、分、秒。到达目标时间后归零并显示祝福，不滚动到下一年。
- 使用 [UTCTime 免费接口](https://utctime.app/api) `https://utctime.app/api/now`：无需注册或密钥，支持 CORS，官方说明服务器经过 NTP 校时；已实测返回 `unix_ms` 与跨域响应头。公开限额为每 IP 每秒 10 次。
- 页面打开时校时，前台每 10 分钟同步一次，恢复联网和退出模拟模式时立即同步。请求 5 秒超时，校时按半程往返时间近似补偿网络延迟，秒级显示不代表绝对零误差。
- 首次校时失败时使用设备时间；后续失败时继续使用上次网络时间锚点。已校时的时钟使用 `performance.now()` 推进，防止设备手动改时影响倒计时。页面会标注本地时间、网络校时或模拟时间。
- **隐藏入口**：2.5 秒内连续点击日期 5 次，或按 **Ctrl+Alt+D**。面板支持精确到秒的北京时间输入，应用后同步切换句子、日期、往期和倒计时；设定后的时间继续走动。
- 「收起」或 Esc 只关闭面板，保留模拟时间；「退出并恢复真实时间」清除模拟时间并重新校时。模拟设置不写入本地存储，刷新即可恢复真实时间。

## 使用方法

1. 下载或克隆本仓库，保持上述文件的相对位置。
2. 将仓库部署到 GitHub Pages 或任意静态服务器。
3. 本地预览时，在仓库目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。不要直接双击 HTML 文件，因为浏览器可能阻止读取本地数据文件。

网站使用相对路径，支持 GitHub Pages 的项目子目录部署。没有 npm 依赖或构建步骤。

## 数据文件格式

每行一条记录，字段之间用制表符或空格分隔：

```text
日期  序号  Base64编码的句子
```

- 日期格式：`yyyy-mm-dd`，使用真实日期并补齐月、日的两位数字。
- 序号：如 `001`，用于维护数据，页面按日期排序。
- 句子：UTF-8 文本的 Base64 编码。
- 每个日期保留一条记录；重复日期会采用文件中最后一条记录。

现有文件包含 2026-09-29 至 2026-12-20 的 83 条记录。新增或修改句子只需编辑数据文件；往期数量由实际记录计算。

**Base64 是编码，不是加密或访问控制。** 它能避免直接浏览数据文件时一眼看到句子，但静态网站的数据可被下载和解码。页面只解码当天及已展开的往期内容，无法阻止读者自行查看未来记录。

## 古早版语录

新增 `考研每日一句_古早版.txt`，以 UTF-8 明文保存 2026-01-01 至 2026-09-28 的 271 条每日语录。每个自然日各有一句，周末和节假日与其他学习日采用相同的鼓励风格。

文件与 `index.html` 放在同一目录，每行格式如下，字段之间用制表符分隔，句子可保留空格：

```text
日期  序号  明文句子
```

页面按北京时间的日期选择数据：2026-09-29 之前只读取古早版；从 2026-09-29 起，今日一句读取原有 Base64 文件，往期回看合并两份文件。两份数据连续覆盖 2026-01-01 至 2026-12-20，共 354 天，按日期衔接，不依赖两份文件的编号连续。

开发者模式调整到早期日期时，只依赖古早版文件，原有 Base64 文件不可用也不会影响当天语录显示。2026-01-01 之前没有语录时沿用原有无记录提示；切回后续日期后会加载编码版，往期仍只展示模拟日期之前的句子。

## 字体与自定义

页面实际使用 `./fonts/LXGWWenKai-Regular.ttf`。字体来自 [霞鹜文楷](https://github.com/lxgw/LxgwWenKai)。如需改用 WOFF2，将文件放入 `fonts/`，同时修改 `index.html` 中 `@font-face` 的 `src` 路径和格式。

- 修改 `DATA_URL` 常量可更换数据文件路径。
- 修改 `:root` 和深色配色中的 CSS 变量可调整主题颜色。
- 配色偏好使用本地存储键 `kaoyan-theme`；删除该键即可恢复跟随系统。
- 日期、倒计时和开发者模式输入统一按北京时间（UTC+8），与访问者设备时区无关。
