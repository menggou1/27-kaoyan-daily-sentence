# 考研每日一句

一个部署在 GitHub Pages 的轻量静态网站，每天显示一句考研鼓励语。保留暖色纸张卡片和霞鹜文楷字体，无需构建或后端服务。

## 功能

- **页面标识**：左上角显示原创书页与星光 SVG 图标，以及「考研每日一句」；随日间、夜间主题调整配色。
- **标签页图标**：浏览器标签页使用同款书页与星光图标，文件为 `favicon.svg`。
- **今日一句**：根据北京时间的日期，匹配并解码当天的句子。2026 年显示 `mm-dd`，其他年份显示 `yyyy-mm-dd`。
- **往期回看**：点击卡片下方的「往期每日一句」展开列表，按日期从近到远显示所有今天之前的句子，并标注日期和总数。列表不包含今天或未来内容，展开时才解码往期句子。
- **夜间阅读**：首次访问跟随系统配色；点击右上角的「夜间阅读 / 日间阅读」切换，并在本浏览器保存选择。浏览器禁用本地存储时，仍可切换当前页面。
- **仓库入口**：页面左下角提供带 GitHub 图标的按钮，在新标签页打开 [项目仓库](https://github.com/menggou1/27-kaoyan-daily-sentence)。
- **跨日更新**：页面跨过北京时间午夜时自动更新日期、句子和往期列表，无需刷新；从后台回到页面时立即检查时间。
- **阅读与无障碍**：适配手机，往期长列表在卡片内滚动；支持键盘展开和切换配色，尊重系统的减少动画设置。
- **卡片背面**：点击「今天还剩多久」翻面，以放大的「今日余量」为标题，查看次日北京时间零点的倒计时钟。24 小时表盘与三根指针倒走，外圈显示剩余量；水平条从左向右推进，暖橙色剩余区段和数字更醒目。午夜倒计时回到新一天的余量、水平条重新起步。沿用原校时与模拟时间，原考试倒计时的样式和计算保持不变。
- **日历总览**：只显示 2026 年，年、季、月、相邻句子和键盘导航均不会越界。支持回到今天和定位考试；实际或模拟日期不在 2026 年时停留在年内边界，并禁用今日入口。年视图整月可点击放大，季/月视图可选日期；每日一句及其标记仅向今天与往期开放，未来内容不能提前读取或复制。
- **日期状态与冲刺区间**：已过日期淡墨，今天描边，12 月 19、20 日实色并分别标明第一/第二天；今日至 12 月 20 日以窄幅浅色条带连接，按周形成完整区间。条带使用独立底层，日期、今日边框、考试填色与选中外圈完整显示在其上。悬停日期时显示浅底、描边和轻微阴影；入场使用 60 毫秒的快速缓出，快速划过至少保持 160 毫秒后再用 180 毫秒淡出，停留较久则随鼠标移出退场，再次移入会取消并续期待退场计时。鼠标一次跨过多个日期时，优先读取合并采样点，并沿相邻采样点的线段按经过顺序补亮；从整周左侧空隙直接跳到右侧空隙也能补亮。日期坐标缓存，滚动、缩放、字体加载和视图更新后重新测量。减少动画偏好下只响应实际悬停，不保留轨迹与延时，键盘焦点同样可见。12 月 20 日后的日期同样淡化，但不标「已过」。今日恰为考试日时同时标识。
- **剩余时间与冲刺动效**：两天考试各自显示与今天、所选日期的自然日距离，使用「距…」「当天」「…已过」表述，避免负天数。两条水平条仍从左向右推进，统一使用暖橙色强调右侧剩余区段，已用时间淡化；今日余量显示剩余数字，日历不显示考前百分比，并以小字说明进度条仅作时间示意，不代表个人备考进度。今日保留流动纹理与箭头节拍，日历采用细线、位置标记与缓慢掠光，动效各不相同；最后阶段加快节奏。日历进度从 2026 年 1 月 1 日至初试第一天 08:30 计算，目标到达后抵达终点并停止动效。减少动画偏好下保留静态进度。
- **阅读细节**：句子支持前后日浏览、复制、重试，额外提供「读今日」快捷入口。加载提示不显示数据文件或拼接方式；日历和页面使用细圆角滚动条，往期列表隐藏滚动条但保留滚动操作。
- **日历键盘操作**：方向键移动一天或一周，Home/End 移动到本周首尾，Esc 关闭日历并恢复入口焦点。手机点击日期后自动滚到句子；键盘导航保持日期焦点。

当天无记录时显示「不在2027考研初试备考时间」，仍可回看已有往期；备考开始前显示往期空状态。加载失败或单条解码失败会显示对应提示。

## 校时、倒计时与开发者模式

- 日期下方显示距离 **2026-12-19 08:30:00（北京时间）**的天、时、分、秒。到达目标时间后归零并显示祝福，不滚动到下一年。
- 使用 [UTCTime 免费接口](https://utctime.app/api) `https://utctime.app/api/now`：无需注册或密钥，支持 CORS，官方说明服务器经过 NTP 校时；已实测返回 `unix_ms` 与跨域响应头。公开限额为每 IP 每秒 10 次。
- 页面打开时校时，前台每 10 分钟同步一次，恢复联网和退出模拟模式时立即同步。请求 5 秒超时，校时按半程往返时间近似补偿网络延迟，秒级显示不代表绝对零误差。
- 首次校时失败时使用设备时间；后续失败时继续使用上次网络时间锚点。已校时的时钟使用 `performance.now()` 推进，防止设备手动改时影响倒计时。页面会标注本地时间、网络校时或模拟时间。
- **隐藏入口**：2.5 秒内连续点击日期 5 次，或按 **Ctrl+Alt+D**。面板支持精确到秒的北京时间输入，应用后同步切换句子、日期、往期和倒计时；设定后的时间继续走动。
- 「收起」或 Esc 只关闭面板，保留模拟时间；「退出并恢复真实时间」清除模拟时间并重新校时。模拟设置不写入本地存储，刷新即可恢复真实时间。

## 使用方法

1. 下载或克隆本仓库，保持上述文件的相对位置。
2. 将仓库部署到 GitHub Pages 或任意静态服务器。
3. 本地预览时，在仓库目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。不要直接双击 HTML 文件，因为浏览器可能阻止读取本地数据文件。

网站使用相对路径，支持 GitHub Pages 的项目子目录部署。没有 npm 依赖或构建步骤。

## 数据文件格式

每行一条记录，字段之间用制表符或空格分隔：

```text
日期  序号  Base64编码的句子
```

- 日期格式：`yyyy-mm-dd`，使用真实日期并补齐月、日的两位数字。
- 序号：如 `001`，用于维护数据，页面按日期排序。
- 句子：UTF-8 文本的 Base64 编码。
- 每个日期保留一条记录；重复日期会采用文件中最后一条记录。

现有文件包含 2026-09-29 至 2026-12-20 的 83 条记录。新增或修改句子只需编辑数据文件；往期数量由实际记录计算。

**Base64 是编码，不是加密或访问控制。** 它能避免直接浏览数据文件时一眼看到句子，但静态网站的数据可被下载和解码。首页解码当天及已展开的往期内容；日历只展示所选日期已经到来的句子，未来句子等到当天开放。这是阅读节奏设计，不是对静态数据文件的访问限制。

## 古早版语录

新增 `考研每日一句_古早版.txt`，以 UTF-8 明文保存 2026-01-01 至 2026-09-28 的 271 条每日语录。每个自然日各有一句，周末和节假日与其他学习日采用相同的鼓励风格。

文件与 `index.html` 放在同一目录，每行格式如下，字段之间用制表符分隔，句子可保留空格：

```text
日期  序号  明文句子
```

页面按北京时间的日期选择数据：2026-09-29 之前只读取古早版；从 2026-09-29 起，今日一句读取原有 Base64 文件，往期回看合并两份文件。两份数据连续覆盖 2026-01-01 至 2026-12-20，共 354 天，按日期衔接，不依赖两份文件的编号连续。

开发者模式调整到早期日期时，只依赖古早版文件，原有 Base64 文件不可用也不会影响当天语录显示。2026-01-01 之前没有语录时沿用原有无记录提示；切回后续日期后会加载编码版，往期仍只展示模拟日期之前的句子。

## 字体与自定义

页面实际使用 `./fonts/LXGWWenKai-Regular.ttf`。字体来自 [霞鹜文楷](https://github.com/lxgw/LxgwWenKai)。如需改用 WOFF2，将文件放入 `fonts/`，同时修改 `index.html` 中 `@font-face` 的 `src` 路径和格式。

- 修改 `DATA_URL` 常量可更换数据文件路径。
- 修改 `:root` 和深色配色中的 CSS 变量可调整主题颜色。
- 配色偏好使用本地存储键 `kaoyan-theme`；删除该键即可恢复跟随系统。
- 日期、倒计时和开发者模式输入统一按北京时间（UTC+8），与访问者设备时区无关。
- 新增视图样式在 `extras.css`，背面交互在 `extras.js`，日历交互在 `calendar.js`。它们通过 `window.KaoyanExtras` 复用原有校时与数据加载，不重复成功的数据请求。
- 考试两天沿用本站日期设置；日历的天数是两个日期之间的自然日之差，原倒计时仍计算到第一天 08:30 的实际时长。

## 浏览器验证

运行 `node tests/ui-check.cjs`，需要 Node.js、可解析的 Playwright 包及其 Chromium。该脚本会自行启动仅本机可访问的临时静态服务器，并模拟校时接口，不请求真实时间服务。网站本身仍无需 npm 依赖或构建。

可用 `NODE_PATH` 指定现有 Playwright 包目录，`BROWSER_EXECUTABLE` 指定已安装 Chromium 可执行文件（包括 Microsoft Edge），`SCREENSHOT_DIR` 指定可选截图输出目录。当前 Microsoft Edge（Chromium）验证 **154 项通过**，包含原倒计时保留、日历入口默认与悬停配色、时间示意说明、倒走指针、两种不同动效与统一暖色剩余区段、今日斜纹在桌面／手机与日间／夜间主题下的普通／加速循环截图一致性及宽度变化稳定性、日期悬停的最短播放、再次移入、内部文字移动与关闭清理、未来句子锁定、区间层叠、2026 年导航边界、考后状态、午夜／跨年处理、三级缩放、320–1440px 无横向溢出、默认／减少动画、隐藏滚动条后的滚动、失败重试与键盘导航。

单独运行 `node tests/calendar-hover-runner.cjs` 可执行 **28 项**悬停专项检查：60 毫秒入场、首个 16 毫秒的显亮程度、单次跨越整周的正反向移动、实际终点驻留、长时间悬停后真实鼠标移出的即时释放、行间空隙、竖向与斜向穿越、合并采样中的转弯、连续 120 次横扫、离开浏览器后的轨迹断开、季／年视图切换、实际滚动后的坐标失效，以及减少动画和触摸操作。加 `--baseline` 会加载当前 Git HEAD 中已提交的 `calendar.js` 和 `extras.css`，输出对比结果而不因旧版本缺少新能力中止。

2026-10-09 的本机对比：原入场 180 毫秒，16 毫秒时描边不透明度约 8%；新入场 60 毫秒，同一时点约 84%。单次事件横跨 7 格的正反向测试在旧版漏亮、新版完整亮起。120 次暖缓存横扫的事件处理平均约 0.07 毫秒，P95 约 0.2 毫秒，无布局读取；这些数值是本机 JavaScript 开销，不含浏览器绘制和设备输入延迟。

鼠标速度没有通用的稳定边界：实际表现还取决于鼠标采样、浏览器事件合并、屏幕刷新和设备负载。[W3C Pointer Events 规范](https://www.w3.org/TR/pointerevents4/#coalesced-events)说明浏览器可能合并快速移动的采样点。本实现补齐已收到采样点之间的线段，不按像素逐点扫描，因此一条线段跨越整周也不会因缺少中间事件漏格；但两个采样点之间未被设备报告的转弯无法准确还原，同一刷新帧内跨过的多格可能同时显亮。离开窗口、滚动或重新渲染后主动断开旧轨迹，避免把未知路径误认为经过日期。
