# 考研每日一句

一个部署在 GitHub Pages 的轻量静态网站，每天显示一句考研鼓励语。保留暖色纸张卡片和霞鹜文楷字体，无需构建或后端服务。

## 功能

- **今日一句**：根据访问者设备的本地日期，匹配并解码当天的句子。2026 年显示 `mm-dd`，其他年份显示 `yyyy-mm-dd`。
- **往期回看**：点击卡片下方的「往期每日一句」展开列表，按日期从近到远显示所有今天之前的句子，并标注日期和总数。列表不包含今天或未来内容，展开时才解码往期句子。
- **夜间阅读**：首次访问跟随系统配色；点击右上角的「夜间阅读 / 日间阅读」切换，并在本浏览器保存选择。浏览器禁用本地存储时，仍可切换当前页面。
- **仓库入口**：卡片左上角提供带 GitHub 图标的按钮，在新标签页打开 [项目仓库](https://github.com/menggou1/27-kaoyan-daily-sentence)。
- **跨日更新**：页面跨过本地午夜时自动刷新；从后台回到页面时也会检查日期。
- **阅读与无障碍**：适配手机，往期长列表在卡片内滚动；支持键盘展开和切换配色，尊重系统的减少动画设置。

当天无记录时显示「不在2027考研初试备考时间」，仍可回看已有往期；备考开始前显示往期空状态。加载失败或单条解码失败会显示对应提示。

## 使用方法

1. 下载或克隆本仓库，保持上述文件的相对位置。
2. 将仓库部署到 GitHub Pages 或任意静态服务器。
3. 本地预览时，在仓库目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。不要直接双击 HTML 文件，因为浏览器可能阻止读取本地数据文件。

网站使用相对路径，支持 GitHub Pages 的项目子目录部署。没有 npm 依赖或构建步骤。

## 数据文件格式

每行一条记录，字段之间用制表符或空格分隔：

```text
日期  序号  Base64编码的句子
```

- 日期格式：`yyyy-mm-dd`，使用真实日期并补齐月、日的两位数字。
- 序号：如 `001`，用于维护数据，页面按日期排序。
- 句子：UTF-8 文本的 Base64 编码。
- 每个日期保留一条记录；重复日期会采用文件中最后一条记录。

现有文件包含 2026-09-29 至 2026-12-20 的 83 条记录。新增或修改句子只需编辑数据文件；往期数量由实际记录计算。

**Base64 是编码，不是加密或访问控制。** 它能避免直接浏览数据文件时一眼看到句子，但静态网站的数据可被下载和解码。页面只解码当天及已展开的往期内容，无法阻止读者自行查看未来记录。

## 字体与自定义

页面实际使用 `./fonts/LXGWWenKai-Regular.ttf`。字体来自 [霞鹜文楷](https://github.com/lxgw/LxgwWenKai)。如需改用 WOFF2，将文件放入 `fonts/`，同时修改 `index.html` 中 `@font-face` 的 `src` 路径和格式。

- 修改 `DATA_URL` 常量可更换数据文件路径。
- 修改 `:root` 和深色配色中的 CSS 变量可调整主题颜色。
- 配色偏好使用本地存储键 `kaoyan-theme`；删除该键即可恢复跟随系统。
- 日期以访问者的本地时区为准，不固定为北京时间。
